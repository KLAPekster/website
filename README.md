# klapekster.be

De website van KLAPekster, de app waarin je vogelwaarnemingen inspreekt. GitHub bouwt de site zelf uit deze bestanden; het plan erachter staat in `ontwerp/website/PLAN.md` van de app.

Een tekst wijzigen: open de pagina hierboven (`index.md`, `privacy.md`, `meedoen.md`, `bedankt.md`, `contact.md`), klik op het potloodje, pas aan en kies "Commit changes". Een minuut later staat het online.
